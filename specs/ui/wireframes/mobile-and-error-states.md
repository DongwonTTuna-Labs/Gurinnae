# 모바일 및 오류 상태 Wireframe

## 1. 모바일 사건 페이지

```text
┌──────────────────────────────┐
│ ← 사례       이상 징후      │
│ 동일 조건 중앙값의 5.0배... │
│ ⚠ 위법성 판단 아님          │
├──────────────────────────────┤
│ 2,400,000원 / 480,000원     │
│ 5.0배 · n=12 · VAT 포함     │
├──────────────────────────────┤
│ [핵심 사실] [근거] [소명]   │
│                              │
│ FACT ... [근거 2]            │
│ LIMITATION ... [근거 1]      │
├──────────────────────────────┤
│ 비교표 → 가로 스크롤         │
│ 항목 | 대상 | 중앙값 | 조건  │
├──────────────────────────────┤
│ [정정 이력] [방법론]         │
└──────────────────────────────┘
```

sticky bottom CTA는 사용하지 않는다. 정정 요청은 문서 끝과 overflow menu에 제공한다.

## 2. Source stale

```text
일부 데이터 갱신이 지연 중입니다.
나라장터 계약 자료의 마지막 정상 수집: 2026-01-28 03:00 KST
이 페이지는 2026-01-27까지 확보된 자료를 기준으로 합니다.
[데이터 상태 보기]
```

## 3. 철회

```text
게시 철회
핵심 비교 단위 오류가 확인되어 2026-02-05 이 게시물을 철회했습니다.
원래 결론은 더 이상 유효하지 않습니다.
[오류 설명] [revision history] [재발 방지 조치]
```

원래 제목은 history 맥락에서만 보여주며 search snippet에는 철회 notice를 우선한다.

## 4. 빈 검색 결과

```text
선택한 조건에서 공개된 사례가 없습니다.

[필터 초기화] [수집 범위 확인]
```

## 5. Public API 오류

```text
현재 이 자료를 불러오지 못했습니다.
기존 공개 내용의 상태를 확인하는 중이며, 잠시 후 다시 시도할 수 있습니다.
```

stack trace, database ID, internal object key 금지.
