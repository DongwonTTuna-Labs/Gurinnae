## 검색·목록 규칙

- 검색 결과는 일치한 필드를 설명하고 private object의 존재를 암시하지 않는다.
- 기본 정렬은 query relevance와 안정된 tie-breaker다. anomaly ratio, 조회수, 공유 수를 사용하지 않는다.
- 필터와 cursor는 URL에 직렬화해 재현·공유 가능하게 한다.
- 검색어가 짧거나 결과가 없으면 예시와 coverage gap을 설명한다.
- raw search query를 analytics에 전송하지 않는다. 길이 bucket과 결과 수 bucket만 허용한다.
- compact에서 필터는 dialog/drawer로 이동하되 현재 적용 필터와 결과 수를 항상 표시한다.
