# 공개 기관·업체·계약 상세 Wireframe

## 기관 상세

```text
┌────────────────────────────────────────────────────────────────────┐
│ 기관 · 가상새빛시청                                                │
│ 식별자/기관 유형/지역 · 데이터 범위 2025-01-01~2026-07-09          │
├────────────────────────────────────────────────────────────────────┤
│ 이 페이지는 공개 계약의 설명적 맥락이며 청렴도·부패 순위가 아닙니다│
├────────────────────────────────────────────────────────────────────┤
│ 수집 계약 1,240건  공개 사례 3건  설명 완료 2건  정정 1건          │
│ 분모·누락 source·갱신 시각 [coverage 보기]                         │
├────────────────────────────────────────────────────────────────────┤
│ 계약 추이              계약 방식 분포             품목 범주         │
│ [accessible chart]     [accessible table]         [table]           │
├────────────────────────────────────────────────────────────────────┤
│ 공개 사례 [상태] [방법론] [기간]                                   │
│ · 확인된 사실/중요한 미확인/소명 상태를 카드에 함께 표시           │
├────────────────────────────────────────────────────────────────────┤
│ 계약 [검색] [기간] [계약 방식] [다운로드]                           │
└────────────────────────────────────────────────────────────────────┘
```

## 업체 상세

- 기관 상세와 같은 coverage·분모·상태 원칙을 사용한다.
- 대표자 개인 신상, 주소 상세, 가족·관계 추론은 공개 근거와 법적 필요가 승인된 범위만 표시한다.
- 공유 주소·연락처 signal은 확인 전 공개하지 않는다.
- “상위”, “위험”, “의심 업체” badge를 사용하지 않는다.

## 계약 상세

```text
계약 기본 정보 → line item → 변경 이력 → 관련 공고/낙찰 → 공개 사건 연결
→ 원본 source/provenance → 데이터 품질·누락 → revision
```

- 원본 금액과 정규화 금액을 구분한다.
- VAT, 단위, bundle, 설치·교육·유지보수, 통화·환율, 계약 변경을 같은 표에 섞지 않는다.
- 계약에 공개 사건이 없다는 사실을 “문제 없음”으로 표현하지 않는다.
- source가 수정되면 관측 시각별 원본 hash를 보존하고 최신/이전 값을 구분한다.
