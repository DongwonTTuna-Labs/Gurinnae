## Data contracts

| Operation | API | Method | Path | Request Schema | Response Schema |
|---|---|---|---|---|---|
| `exchangeSubscriptionManagementToken` | `submission-api` | `POST` | `/v1/submission-session/subscription-management:exchange` | `exchangeSubscriptionManagementTokenRequest` | `ExchangeSubmissionSessionResult` |
| `getSubscription` | `submission-api` | `GET` | `/v1/subscription-session` | `getSubscriptionQuery` | `SubscriptionResponse` |
| `updateSubscription` | `submission-api` | `PATCH` | `/v1/subscription-session` | `updateSubscriptionRequest` | `updateSubscriptionReceipt` |
| `unsubscribe` | `submission-api` | `POST` | `/v1/subscription-session:unsubscribe` | `unsubscribeRequest` | `unsubscribeReceipt` |

모든 Submission operation은 raw bearer token을 canonical URL에 남기지 않는다. Magic token은 BFF가 one-time exchange 요청 입력으로만 사용하고 이후에는 scoped submission session으로 전환한다. 교환 성공과 실패 모두 `/subscription/manage`로 이동하며 token을 URL에 남기지 않는다.

## Responsive contract

- Compact에서 주요 action과 critical unknown/blocker를 숨기지 않는다.
- Primary table은 의미가 보존되는 record list로 재배치한다.
- Context panel은 drawer 또는 inline section으로 이동하며 focus가 복원된다.
- Horizontal scrolling만으로 핵심 작업을 해결하지 않는다.

## Accessibility contract

- H1은 정확히 하나다.
- Section heading level을 건너뛰지 않는다.
- Keyboard만으로 전체 task를 완료할 수 있다.
- 최소 pointer target은 44×44 CSS px다.
- 상태는 색상에만 의존하지 않는다.
- Dialog/drawer 종료 후 원래 trigger로 focus를 되돌린다.
- Chart가 있으면 같은 사실을 담은 표 또는 문장형 대안을 제공한다.
- Save/submit/session exchange 결과를 적절한 live region으로 알린다.
