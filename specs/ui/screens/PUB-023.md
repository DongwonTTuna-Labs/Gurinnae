## Data contracts

| Operation | API | Method | Path | Request Schema | Response Schema |
|---|---|---|---|---|---|
| `getFundingContent` | `public-api` | `GET` | `/v1/content/funding` | `getFundingContentQuery` | `FundingContentResponse` |
| `listTransparencyReports` | `public-api` | `GET` | `/v1/transparency-reports` | `listTransparencyReportsQuery` | `TransparencyReportsPage` |
| `downloadTransparencyReport` | `public-api` | `GET` | `/v1/transparency-reports/{reportId}/download` | `DownloadTransparencyReportRequestV1` | `TransparencyReportDownloadV1` |

`download-report`의 `reportId`는 사용자가 선택한 `listTransparencyReports.items[].id`에서만 가져온다. 같은 item의 `href`는 정확히 `/v1/transparency-reports/{reportId}/download`여야 하며 다른 ID나 URL을 조합하지 않는다. 선택적 `format`은 `JSON | CSV`의 닫힌 집합이고 기본값은 `JSON`이다.

다운로드는 같은 `reportId`의 현재 승인된 immutable `FUNDING_DISCLOSURE` revision, revision digest, projection digest와 public content digest에 결속한다. 분모 근거가 없거나 grouping이 다투어지면 실제 `UNKNOWN` 사유를 표시하며 수치나 낮은 concentration band를 추론하지 않는다.

## Responsive contract

- Compact에서 주요 action과 critical unknown/blocker를 숨기지 않는다.
- Primary table은 의미가 보존되는 record list로 재배치한다.
- Context panel은 drawer 또는 inline section으로 이동하며 focus가 복원된다.
- Horizontal scrolling만으로 핵심 작업을 해결하지 않는다.

## Accessibility contract

- H1은 정확히 하나다.
- Section heading level을 건너뛰지 않는다.
- Keyboard만으로 전체 task를 완료할 수 있다.
- 최소 pointer target은 44×44 CSS px다.
- 상태는 색상에만 의존하지 않는다.
- Dialog/drawer 종료 후 원래 trigger로 focus를 되돌린다.
- Chart가 있으면 같은 사실을 담은 표 또는 문장형 대안을 제공한다.
- Save/submit/session exchange 결과를 적절한 live region으로 알린다.
