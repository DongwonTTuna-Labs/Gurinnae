# 39. 콘텐츠 디자인과 마이크로카피

## 1. 목적

구린네의 문구는 법적 위험을 피하기 위한 완곡어법만이 아니라 사용자가 사실·계산·추론·소명을 구분하도록 돕는 인터페이스다.

## 2. Voice

- 차분하고 직접적
- 근거를 먼저 제시
- 불확실성을 구체적으로 설명
- 비전문가에게 이해 가능
- 기관·업체·개인을 조롱하지 않음
- AI를 권위로 내세우지 않음
- 오류와 정정을 숨기지 않음

## 3. 상태 용어

| 내부 상태 | 공개 label | 설명 |
|---|---|---|
| `PUBLISHED_AS_ANOMALY` | 이상 징후 공개 | 공개자료 비교에서 설명이 필요한 차이가 확인됨 |
| `EXPLAINED` | 설명 확인 | 추가 자료로 주요 차이에 합리적 설명이 확인됨 |
| `REFERRED` | 외부 기관 전달 | 감사·수사·언론 등 외부 기관에 자료를 전달함 |
| `OFFICIALLY_CONFIRMED` | 공식 확인 | 공식 감사·수사·판결 등에서 문제가 확인됨 |
| `CORRECTED` | 정정 | 공개 내용 일부가 수정됨 |
| `RETRACTED` | 철회 | 중대한 근거 오류 등으로 기존 공개를 철회함 |

“의혹 확정”, “혐의 있음”, “걸림”을 상태로 사용하지 않는다.

## 4. Claim 문장 패턴

### 사실

> 나라장터 공개 계약자료에는 계약금액이 24,000,000원, 수량이 10개로 기재되어 있습니다.

### 계산

> 공개자료의 수량을 기준으로 계산한 단가는 개당 2,400,000원입니다.

### 비교

> 비교 조건을 충족한 12건의 중앙값 480,000원보다 5.0배 높습니다.

### 한계

> 공개된 계약자료만으로는 설치·교육·유지보수 비용이 포함되었는지 확인되지 않았습니다.

### 당사자 소명

> 업체는 2026년 7월 8일 제출한 답변에서 해당 금액에 3년 유지보수가 포함됐다고 밝혔습니다. 구린네는 제출된 유지보수 내역 중 계약 기간을 확인했으나 시장가격 적정성은 확인하지 못했습니다.

### 공식 결과

> 감사원은 2027년 2월 3일 공개한 감사 결과에서 계약 절차 위반을 확인했습니다.

주어와 출처를 명시한다. “알려졌다”, “드러났다”를 근거 없이 쓰지 않는다.

## 5. 제목

형식:

```text
[기관/사업] + [관찰된 현상] + [필요 시 상태]
```

예:

- 가상새빛시청 안전모 계약에서 비교군보다 높은 단가가 관찰됨
- 가상한강공단 서버 유지보수 계약의 묶음 비용 설명 확인
- 가상동부청 차량 임차 비교에서 단위 오류를 정정함

제목에 물음표로 범죄를 암시하지 않는다.

## 6. 버튼

동작을 구체적으로 쓴다.

좋음:

- 근거 원문 보기
- 필터 적용
- 답변 임시 저장
- 답변 제출
- 검토 변경 요청
- 최신 snapshot 게시
- 정정 요청 접수

나쁨:

- 확인
- 예
- 처리
- 실행
- 제출하기(무엇을?)
- AI 분석

## 7. 오류

패턴:

```text
무엇이 실패했는지
사용자 입력이 보존됐는지
어떻게 해결할지
지원용 reference
```

예:

> 답변을 제출하지 못했습니다. 입력한 내용은 임시 저장되어 있습니다. 네트워크 연결을 확인한 뒤 다시 제출해 주세요. 참조: RSP-4F82

금지:

> 알 수 없는 오류가 발생했습니다.

## 8. Empty state

실제 0건:

> 이 조건에 해당하는 공개 사례가 없습니다.

coverage 부족:

> 이 기간의 계약자료는 아직 수집 범위에 포함되지 않습니다. 데이터 범위를 확인해 주세요.

권한:

> 이 역할로 볼 수 있는 작업이 없습니다.

filter empty:

> 선택한 필터에 맞는 결과가 없습니다. 기간 또는 상태 필터를 줄여 보세요.

## 9. Freshness

> 지방재정365 자료는 2026년 7월 8일 03:20 이후 갱신되지 않았습니다. 해당 source를 사용하는 금액과 계약 수는 최신이 아닐 수 있습니다.

“실시간”은 실제 SLA와 데이터 특성이 뒷받침되지 않으면 사용하지 않는다.

## 10. 소명 요청

중립적 질문:

> 공개 계약자료에는 품목 단가가 개당 2,400,000원으로 계산됩니다. 이 금액에 포함된 제품, 설치, 교육, 유지보수 항목과 각각의 금액을 확인할 수 있는 자료를 제공해 주시겠습니까?

나쁜 질문:

> 왜 시중가보다 5배나 비싸게 구매했습니까?

## 11. 정정

> 2026년 7월 10일, 비교군에 단위가 다른 계약 2건이 포함된 사실을 확인해 중앙값과 비교 배수를 수정했습니다. 이전 값은 5.0배였고 수정된 값은 3.7배입니다.

변경 전·후와 이유를 함께 쓴다.

## 12. AI 문구

허용:

> 조사 보조 모델이 추가 확인 항목 3개를 제안했습니다. 사람이 검토하기 전에는 사건 사실에 반영되지 않습니다.

금지:

> AI가 비리 가능성을 92%로 판단했습니다.

## 13. 날짜·시간·숫자

- 공개 화면: `2026년 7월 10일 14:30 (KST)`
- 내부 ID는 별도
- 금액: 통화, VAT, 단위
- ratio는 소수점 정책 고정
- missing은 0이 아니라 `확인되지 않음`
- approximate는 `약`
- relative time은 보조
- timezone 명시
- 범위 dash semantics

## 14. 개인정보·민감정보

- 필요 이상의 개인 이름·연락처 금지
- 공개 담당자 직책만 필요할 수 있음
- redaction 이유 category
- “익명”과 “비공개” 구분
- submitted statement와 editor summary 구분
- 법률 검토 중인 정보를 추측하지 않음

## 15. 내부 copy

내부라고 해서 단정적·비하 표현을 허용하지 않는다.

금지:

- 확실한 비리
- 저 업체 또 해먹음
- 범인
- AI가 잡음

내부 상태와 reason code를 사용한다.

## 16. 번역

초기 canonical 언어는 한국어다. 다국어 도입 시:

- 공식 source 원문과 번역 구분
- human-reviewed legal/editorial copy
- revision별 번역 동기화
- 숫자/통화 locale
- 번역 지연 표시
- response party가 제출한 언어 보존

## 17. Copy review checklist

- 누가 말하는지 명확한가?
- source와 시점이 있는가?
- 사실·계산·해석이 구분되는가?
- 가장 중요한 한계가 보이는가?
- 무응답을 인정으로 해석하지 않는가?
- 개인정보가 필요한가?
- 상태와 revision이 명확한가?
- 버튼이 결과를 설명하는가?
- 오류 해결 행동이 있는가?
