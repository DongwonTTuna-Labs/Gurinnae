# 45. 최종 디자인 방향

## 핵심 원칙

구린네는 “가장 센 의혹”을 먼저 보여주는 서비스가 아니다.
**판단에 필요한 정보를 신뢰도와 중요도 순서로 배치하는 서비스**다.

## 정보 우선순위

### 공개 화면

1. 상태와 최신성
2. 확인된 사실
3. 중요한 미확인
4. 당사자 소명
5. 비교 조건과 계산
6. 반대 근거
7. 원본 증거
8. revision·정정

### 내부 화면

1. 긴급 blocker/incident
2. 사용자에게 할당된 다음 작업
3. 오래된 작업과 SLA
4. 사건의 확인/미확인
5. 데이터와 근거
6. AI 제안
7. 부가 통계

### 소명 화면

1. 누가 왜 요청했는지
2. 답변 기한과 공개 범위
3. 질문
4. 첨부 상태
5. 제출 전 검토
6. receipt

## 제품 표정

- calm
- factual
- dense only where work requires it
- no gamification
- no moral judgement through color
- no fear-inducing crime iconography
