## 상호작용

- 검색 autocomplete는 public entity read model만 사용한다.
- 최근 사례 카드의 상태는 텍스트+아이콘으로 표시한다.
- `일부 지연`은 source별 freshness drawer를 연다.
- 화면 첫 진입 시 화려한 count-up이나 위험 점수 animation을 사용하지 않는다.

## 접근성

- 페이지 제목 다음 첫 heading은 미션이다.
- 검색 label은 placeholder에 의존하지 않는다.
- 카드 전체를 link로 만들더라도 내부 버튼과 중첩 link를 만들지 않는다.
- source 상태가 자동 갱신돼도 screen reader를 과도하게 방해하지 않는다.
