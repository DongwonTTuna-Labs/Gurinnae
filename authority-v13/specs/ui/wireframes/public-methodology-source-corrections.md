# 공개 방법론·데이터 출처·정정 Wireframe

## 방법론 상세

```text
┌────────────────────────────────────────────────────────────────────┐
│ PRICE_OUTLIER · version 1.0.0 · 적용 기간                           │
├────────────────────────────────────────────────────────────────────┤
│ 무엇을 탐지하는가 / 무엇을 의미하지 않는가                         │
│ 필요한 필드 / 비교 cohort / 계산식 / 최소 표본 / threshold          │
│ blocker / 알려진 오탐 / 공개 조건 / 변경 이력                       │
├────────────────────────────────────────────────────────────────────┤
│ 합성 예시 [입력] → [포함/제외] → [중앙값] → [signal]               │
│ 계산 다운로드 / JSON schema / rule version                          │
└────────────────────────────────────────────────────────────────────┘
```

## 데이터 출처 상세

- source owner, access type, 검증일, 갱신 주기, coverage, last success, lag, schema version을 표시한다.
- 장애 시 영향받는 지표·페이지·기간을 명시한다.
- API key, parser secret, private endpoint, raw restricted payload는 노출하지 않는다.
- “실시간” 표현은 실제 SLA와 freshness가 충족될 때만 사용한다.

## 정정 상세

```text
정정 상태/발효 시각/중요도
왜 수정했는가
변경 전 → 변경 후
영향받은 claim·차트·다운로드
이전 revision 링크
재발 방지·검증 방식
```

- 철회는 원래 결론이 유효하지 않음을 첫 화면에서 알린다.
- 단순 문구 정리와 결론을 바꾸는 material correction을 구분한다.
- 이전 revision은 역사적 맥락으로 접근 가능하지만 검색 snippet과 공유 preview는 최신 정정 상태를 우선한다.
